# Gebruikershandleiding

## Aanmelden

1. Start de app lokaal en ga naar `/login`.
2. Gebruik de account die met `npm run auth:setup` is aangemaakt.
3. Eén lokale beheerder; geen zelfregistratie.

## Projectstart

1. **Nieuw project** → vul minimaal Project en Verantwoordelijke scan in.
2. Overige velden (nummer met voorloopnullen, datum, uitvoerder, …) later aanvullen.
3. Lees de vijf stappen en de beslisvolgorde Voorkomen → … → BSA/specifieke route.
4. **Opslaan** — status «Opgeslagen» verschijnt pas na serversucces.

## Quickscan

1. Beoordeel de tien controlepunten (Ja / Nee / n.v.t. / nog niet ingevuld).
2. Bij **Nee**: vul een concrete vervolgactie in.
3. «Wie» is optioneel maar aanbevolen (geen taaksysteem of deadlines).

## Materiaalstromen

1. Zet per vaste groep of de stroom voorkomt (Ja/Nee).
2. Vul bij voorkomende stromen bouwfase, hoeveelheid, eenheid, oorzaak en vervolgroute in.
3. **Nog beoordelen** opent een gekoppelde beoordeling.
4. Chemisch afval: alleen Specifieke afvalroute.
5. Bij Nee blijven eerdere details bewaard als inactief.

## Materiaalbeoordeling

1. Gebruik alleen bij extra beoordeling van een specifiek materiaal.
2. Beantwoord conditie, hergebruik, retourbevestiging, recycling.
3. Retourroute alleen als Retour bevestigd = Ja (projectcontrole).
4. Definitieve route leeg laten = «Nog te bepalen».
5. Optioneel: route expliciet overnemen naar de gekoppelde stroom.

## Evaluatie

1. Vul na afloop handmatig werkelijke hoeveelheden, containerwissels en routes in.
2. Beantwoord de vier leerpuntvragen.
3. Geef relevante gecontroleerde info handmatig door aan KAM (buiten de app).

## Onderzoeksvalidatie

- Apart menu `/validation`, niet gekoppeld aan een projectscore.
- Scores 1–5 en Ja/Deels/Nee blijven individueel; geen eindcijfer.
