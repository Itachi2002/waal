# Gebruikershandleiding

## Starten

1. Start de app (`npm run dev` of de online URL).
2. Je komt direct op **Projecten** — er is geen login in de demo.

## Projectstart

1. **Nieuw** → vul minimaal Project en Verantwoordelijke scan in.
2. Overige velden later aanvullen.
3. Lees de vijf stappen en de beslisvolgorde.
4. **Opslaan** — status «Opgeslagen» verschijnt pas na serversucces.

## Quickscan

1. Beoordeel de tien controlepunten (Ja / Nee / n.v.t. / nog niet ingevuld).
2. Bij **Nee**: vul een concrete vervolgactie in.
3. «Wie» is optioneel maar aanbevolen.

## Materiaalstromen

1. Zet per vaste groep of de stroom voorkomt (Ja/Nee).
2. Vul bij voorkomende stromen bouwfase, hoeveelheid, eenheid, oorzaak en vervolgroute in.
3. **Nog beoordelen** opent een gekoppelde beoordeling.
4. Chemisch afval: alleen Specifieke afvalroute.

## Materiaalbeoordeling

1. Gebruik alleen bij extra beoordeling van een specifiek materiaal.
2. Retourroute alleen als Retour bevestigd = Ja.
3. Optioneel: route expliciet overnemen naar de gekoppelde stroom.

## Evaluatie

1. Vul na afloop handmatig werkelijke hoeveelheden en containerwissels in.
2. Beantwoord de vier leerpuntvragen.
3. Geef relevante info handmatig door aan KAM (buiten de app).

## Onderzoeksvalidatie

- Apart menu `/validation`, geen projectscore of eindcijfer.
